# cidrmerge 0.4.3

This patch release adopts [swift-cidr 0.11.0](https://github.com/RouteObjects/swift-cidr/releases/tag/0.11.0) and its accepted compact-coalescing implementation.

- Reuse the sorted range buffer when every range survives. When ranges merge,
  copy the reduced result into fresh storage so it does not retain an
  input-sized result allocation. The policy uses no shrink threshold.
- Preserve exact coverage, deterministic ordering, endpoint behavior and
  caller-owned values. CLI options, raw/JSON output, statistics and checksum
  behavior remain unchanged.
- Update the dependency pin, notices, Core-consumer constraint and minimum-version
  CI gate together. The other seven dependency pins are unchanged.

This is the first cidrmerge release to adopt compact coalescing. Earlier report
publication preserved the experiment; cidrmerge 0.4.2 still used swift-cidr 0.10.1.

Fresh matched Swift 6.4.2 experiments on macOS, native ARM64 Linux and x86-64
Linux retained 948 measured observations and 158 warmups, with complete-output
and independent resource audits. The macOS range-derived workload reproduced a
27.10% paired-median peak-RSS reduction, from 84.67 to 61.73 MiB. This is a
workload-specific memory result, not a general throughput claim. Small CPU
tradeoffs, noisy tiny-input latency and Linux small-input RSS limits remain
explicit in the report.

Full baseline/candidate Debug and Release tests passed on all three platforms,
with additional candidate Swift 6.2.4 ARM64 compatibility. Exact CLI and I/O
comparisons, documentation, external Core consumers and smoke checks passed.
Both timed binaries retained version 0.4.2 to isolate the dependency change;
0.4.3 adds the release-version preparation afterward.

The Swift tools minimum remains 6.2, language mode remains Swift 6, and the
macOS 15/Core iOS 18 deployment floors are unchanged. Distributed archives use
the established Swift 6.2 compatibility toolchain and receive separate release
validation. Historical reports, thresholds and raw results remain preserved.
