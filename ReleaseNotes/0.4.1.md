# cidrmerge 0.4.1

This patch release improves input preparation, typed coverage construction and
raw output formatting while preserving exact coverage and deterministic output.

- Require swift-cidr 0.10.1 and expose the typed coverage construction chain to
  cross-module specialization, allowing ordinary CLI calls to reach specialized
  IPv4 and IPv6 sorting implementations.
- Prepare entirely ASCII input lines directly from bytes while retaining the
  existing strict UTF-8 decoding, Unicode handling, comments and diagnostics for
  other input.
- Bound temporary Foundation read-buffer lifetimes on macOS while preserving
  chunk-boundary handling and missing-final-newline behavior.
- Render raw ranges and CIDRs with swift-cidr's public UTF-8 writers. Canonical
  bytes, IPv4-first ordering, checksums and atomic output behavior are unchanged.
  The renderer still returns the complete output Data.

The Swift tools minimum remains 6.2. Public API signatures, command-line options,
JSON and statistics are unchanged. The separately studied compact-coalescing
implementation is not included; its reports are retained for future work.

Each optimization has preserved matched measurements and correctness checks on
macOS, ARM64 Linux and x86-64 Linux. These experiments use their recorded Swift
6.4.2 builds and qualify specific workloads; their gains are not added together
or presented as a single comparison against 0.4.0. Distributed archives use the
Swift 6.2 compatibility toolchain and receive separate release validation.

For the raw UTF-8 writer experiment, large-output paired-median elapsed time
improved by roughly 8–29% for ranges and 3–17% for CIDRs across the three recorded
platforms. Peak memory was essentially unchanged, and x86-64 two-line output
retained a roughly 2% cost. All observations and follow-ups remain in the
[raw-writer report](../Benchmarks/Results/2026-11-16-raw-utf8-writers/RESULTS.md),
with [publication provenance](../Benchmarks/Results/2026-11-16-raw-utf8-writers-publication.md)
separate from the original experiment snapshot.
