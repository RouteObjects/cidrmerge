# cidrmerge 0.4.2

This patch release reduces input-processing overhead while preserving parsing,
validation, deterministic output and statistics behavior.

- Text and Searchbot input skip canonical-string comparisons used only for
  normalization accounting when `--stats` is absent. Statistics-enabled calls
  retain the existing exact counts. ([#29](https://github.com/RouteObjects/cidrmerge/pull/29))
- Text file and stdin processing use Foundation's public `Data.span` byte view
  for efficient chunk iteration. Existing reads, errors, chunk boundaries,
  pending-line storage and temporary-buffer lifetimes are preserved.
  ([#30](https://github.com/RouteObjects/cidrmerge/pull/30),
  [#31](https://github.com/RouteObjects/cidrmerge/pull/31))
- Add focused normalization-accounting tests and preserve matched correctness
  and performance evidence on macOS, ARM64 Linux and x86-64 Linux.

The Swift tools minimum remains 6.2 and the macOS deployment target remains 15.
Public APIs, CLI options, dependency revisions, raw/JSON output bytes and checksum
behavior are unchanged. Foundation still creates a Data for each read; this
release makes no allocation-removal claim.

The preserved reports describe separate Swift 6.4.2 experiments. Their results
are workload-specific and are not added together as a release-wide speedup.
Distributed archives use the Swift 6.2 compatibility toolchain and receive
separate release validation.
