cidrmerge Third-Party Notices
================================

This file records the third-party Swift package graph resolved for cidrmerge.
Package versions and revisions are taken from the checked-in Package.resolved.

Release product target closure
------------------------------

The cidrmerge executable compiles and links code from the following packages.
CIDRMergeCore itself depends only on swift-cidr; checksum generation and Swift
Crypto remain confined to the CIDRMergeCLI executable closure.

Resolved-only package graph
---------------------------

SwiftPM also records packages required by dependency products that cidrmerge
does not use. They are listed to make the complete Package.resolved closure
auditable, but their product code is not part of the cidrmerge release binary.

swift-asn1 1.7.1
  Revision: a9a5efd40eaf558a2bcd48d64b1d1646be686008
  Source: https://github.com/apple/swift-asn1
  License: Apache License 2.0
  Resolution reason: used by Swift Crypto's separate CryptoExtras product;
    cidrmerge imports only Crypto.

The remaining packages are resolved because swift-cidr offers a separate
CIDRNIO product. cidrmerge depends only on swift-cidr's CIDR product and does
not import or link CIDRNIO or NIOCore.
